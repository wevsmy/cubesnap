# 平面魔方

一个使用 Vue 3、TypeScript 和 Vite 实现的浏览器魔方演示。左侧是可转动、可拖动视角的 Three.js 3D 魔方；右侧用 9 个圆和 54 个交点展示同一份贴纸状态。MathFlow 用于计算圆周动画的位置。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
```

打开终端输出的本地地址，通常为 `http://localhost:5173/`。

```bash
npm run build    # 类型检查并构建到 dist/
npm run preview  # 预览构建结果
```

## 操作

- 拖动左侧魔方可改变观察角度；鼠标滚轮可缩放视图。视角不会自动旋转，也不会改变贴纸状态。
- 点击 `U/D/L/R/F/B` 及带 `'` 的按钮，可沿对应方向转动外层。
- 在右侧沿任意圆环拖动，可实时预览对应 3D 层及圆上的 12 个节点。松手后吸附到一次 90° 转动；拖动距离不足时回弹，不改变魔方状态。鼠标和触摸均可操作。
- 右侧圆环也支持键盘操作：先聚焦圆环，按左、右方向键反向或正向转动。
- `Scramble` 连续执行 16 次随机外层转动；`Undo` 撤销最近一次操作；`Reset` 恢复六面同色。

初始展示的是一组固定的合法混色状态，方便观察贴纸联动。初始状态不计入操作历史，因此刚打开页面时 `Undo` 不可用。

## 圆环与魔方层的对应

每组 3 个同心圆；半径从小到大分别对应轴上的 `-1`、`0`、`+1` 层。中圈的转动为中层操作，仅通过右侧圆环或方向键触发。

| 圆组 | 旋转轴 | 内圈 | 中圈 | 外圈 |
| --- | --- | --- | --- | --- |
| 上方 | y | D | E | U |
| 左下 | x | L | M | R |
| 右下 | z | B | S | F |

每条圆与另外两组圆产生 12 个交点。静止时共显示 9 个背景圆和 54 个节点；转动时只让当前圆及其 12 个节点运动。3D 和二维图共用同一份贴纸状态，动画结束后一起更新颜色。

主要实现位于 `src/App.vue`，页面样式位于 `src/styles.css`。
